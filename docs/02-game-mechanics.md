## 1. 화면 구성 [확정]

브레드크럼: `… League > Create AI agents > Play` → 에이전트를 **만든 뒤(Create AI agents)** **플레이(Play)**하는 흐름.

### 상단 지표 (3종)

| 아이콘 | 예시 값 | 의미 [확정/추론] |
|---|---|---|
| 코인 | `2,250` | **점수**. 코인 수집/챌린지 격파로 증가. [확정: 메인 지표] |
| 하트 | `3` | **생명**. 0이 되면 게임 오버로 추정. [추론] |
| 타이머 | `4:13` | **카운트다운**. 0이면 종료. 제한 시간 내 점수 최대화. [확정: 카운트다운 / 추론: 종료조건] |

### 맵

- **그리드형**: 가로 열 라벨 **A–J (10열)**, 세로 행 존재 → 좌표계 (예: `C4`)로 위치 지정 가능. [확정]
- **미로 구조**: 벽/통로. 경로 탐색 필요. [확정]
- 등장 요소: **에이전트 캐릭터(기사)**, **코인(다수, 산재)**, **적 몬스터**, **보물/특수 타일**. [확정]

### Combat Log 패널

- 우측. 에이전트가 마주친 **챌린지(문제)** + **에이전트 자체의 의사결정 텍스트**가 누적 표시. [확정]
- 관찰된 예시 문제(원문):
  > "...1000 to 1100. A gap is the difference between two consecutive primes. For example, between primes 23 and 29, the gap is 6. What is the largest gap between consecutive primes in the range 1000-1100?"
- 관찰된 에이전트 응답 패턴(원문, 추가 스크린샷):
  > "I need to delegate this code challenge to the **Code Specialist** to find the largest gap between consecutive prime numbers in the range 1000 to 1100. 🔧 Using tool: **CodeExecution**"
- → 챌린지는 **정량 추론/수학/알고리즘 문제** + 에이전트는 **Code Specialist 서브에이전트 + CodeExecution 도구**로 위임하는 패턴이 의도된 설계임이 확인됨. (우리 설계의 Challenge Solver와 1:1 일치 — [agent/prompts/challenge-solver.md](../agent/prompts/challenge-solver.md))

## 2. 목표 [확정]

목표 텍스트(원문):

> **"보물을 찾으면서 모든 코인을 수집하고 챌린지를 물리치세요!"**

→ 3개 동시 과제:
1. **보물 찾기** (탐색)
2. **모든 코인 수집** (커버리지 — 단순 최단경로가 아니라 *수집 최적화*)
3. **챌린지 격파** (정답 제출)

이 셋은 **시간·생명 제약** 아래에서 동시에 최적화해야 하는 다목적 문제.

---

## 3. 에이전트 빌더 UI 구조 [확정 — 스크린샷]

워크샵 "Amazon Bedrock AgentCore를 사용하여 AI 에이전트 생성" 화면 확인:

- **도구 섹션**: ① AgentCore 메모리 ② Amazon Bedrock Guardrails ③ AWS Lambda 함수 (각각 `+` 버튼으로 인스턴스 추가)
- **멀티 에이전트 오케스트레이션**: 슈퍼바이저 1 + **서브 에이전트 최대 5개** ("서브 에이전트 추가 (1/5)")
- 노드 색상 범례: 에이전트(흰)/서브에이전트(노랑)/메모리(파랑)/가드레일(초록)/Lambda(빨강)
- 기본 제공으로 보이는 것: `guardrail` 가드레일, `Pathfinding` Lambda + Pathfinder 서브에이전트
- 우상단 "게임 가이드" 링크 / 하단 "보드 플레이" 버튼

→ 사전 준비물(프롬프트·Lambda 코드·정책)을 슬롯에 그대로 붙여넣는 워크플로우. 슬롯 배치도: [agent/orchestration.md](../agent/orchestration.md).

## 4. 설정 탭 구조 [확정 / 일부 당일]

[objective-and-tabs.png](../assets/key-images/objective-and-tabs.png)에서 확인된 탭:

| 탭 | 내용 | 상태 |
|---|---|---|
| **도구 및 전략** | 에이전트 도구/전략 설정 | [확정: 탭 존재] |
| **보너스** | 보너스 점수 규칙 | **[당일]** 상세 가려짐 |
| **챌린지** | 챌린지 규칙/유형 | **[당일]** 상세 가려짐 |

같은 화면 내 섹션:

- **목표**: (위 확정 텍스트)
- **극대화하는 방법:** → **[당일]** 내용 가려짐. *사실상 채점식/점수 극대화 가이드*. 당일 가장 먼저 읽을 것.
- **추가 규칙** → **[당일]** 내용 가려짐.
- **가이드 및 힌트**: "워크숍 스튜디오 문서에 연습 과정과 추가 팁 포함" [확정]

## 4. 메커니즘 추론 정리

| 항목 | 추론 | 근거 | 당일 확인 |
|---|---|---|---|
| 점수원 | 코인 + 챌린지 격파 (+ 보너스) | 목표 텍스트, 코인 지표 | 정확 배점 |
| 생명 소모 | 적 접촉 / 챌린지 오답 시 -1 추정 | 하트=3, "물리치다" 표현 | 소모 트리거 |
| 종료 조건 | 타이머 0 또는 생명 0 | 카운트다운, 하트 | 동시 만족 시 처리 |
| 챌린지 트리거 | 적/타일 조우 시 문제 출제 | Combat Log + 적 존재 | 출제 방식 |
| 챌린지 형태 | 정답이 명확한 정량 문제(수학/알고리즘) | 소수 gap 예시 | 답안 포맷·채점 |
| 입력 방식 | 에이전트가 자율 이동·답안 생성 | "에이전트를 만들고 개선" | 행동 인터페이스(좌표 이동 / 명령 / 자연어) |

> 위 [추론]은 시뮬레이터 기본 가정으로 사용([sim/](../sim/)). 당일 [확정]값으로 `sim/config.json`만 교체하면 전략 재검증 가능. 라우팅 최적화 실측 결과는 [docs/08-routing-findings.md](08-routing-findings.md).

## 5. 전략적 함의 (요약)

1. **챌린지 = 코드로 푼다**: 소수 gap류 문제는 LLM 암산 시 오답 위험. Code Interpreter / Lambda로 **계산해서** 답을 내면 정답률 ≈ 100%. → 가장 확실한 점수 레버.
2. **경로는 "전수집" 문제**: 단순 A→B 최단이 아니라 *제한 시간 내 코인 가치 합 최대화* (방향성 있는 TSP/예산 제약 탐색). 휴리스틱 경로탐색 도구 품질이 점수 직결.
3. **시간·생명은 예산**: 무의미한 전투/이동 회피. 고가치 코인·보물 우선.
4. **Memory로 상태 누적**: 맵 레이아웃, 푼 챌린지 패턴, 적 위치를 기억해 재방문/재계산 비용 제거.
5. **Guardrails로 출력 규율화**: 답안 포맷 고정, 규칙 이탈 차단.
