# 04. AWS 서비스 치트시트 [확정]

안내자료 4장 기준. 깊은 이해보단 *역할*과 *워크샵에서 할 일* 위주로 정리.

| 서비스/기능 | 쉽게 | 워크샵에서 할 일 | 1등 관점 활용 |
|---|---|---|---|
| **Amazon Bedrock AgentCore** | AI 에이전트가 실제 실행되는 기반 환경 | 에이전트 생성, 역할 정의, 도구/메모리/가드레일 연결 | Supervisor+Sub-Agent 구조의 그릇. 역할 분해가 점수 좌우 |
| **AgentCore Memory** | 중요한 정보를 기억/재사용 | 힌트·키 값·이전 응답 저장·재사용 | 맵·푼 챌린지·적 위치 누적 → 재계산 제거, 후속 가속 |
| **Tools / Gateway** | 외부 도구 연결 통로 | 경로 탐색·코드 실행·데이터 처리 도구 호출 | Navigation·Code Interpreter 도구가 핵심 점수 레버 |
| **Amazon Bedrock Guardrails** | 안전·규칙 준수 안전장치 | 입출력 제어, 부적절 응답 방지, 챌린지 규칙 준수 | 답안 포맷 강제, 규칙 이탈/무의미 행동 차단 |
| **AWS Lambda** | 서버리스 기능 실행 | Tool로 연결된 기능 실행, 결과 활용 | 경로탐색·챌린지 계산을 결정론적으로 정확히 |
| **Amazon SageMaker AI** | 내장 코드 에디터 | Python 코드 작성·수정 | Lambda Tool 코드 빠른 반복 개선 |

## 개념별 워크샵 다룰 내용 [확정]

- **AgentCore**: 에이전트 생성/실행, 역할·행동 정의, 도구 연결, Memory 설정, Guardrails 적용.
- **Memory**: 정보 저장 → 재호출 → System Prompt에서 사용 방식 지시 → 기억 기반 후속 문제 해결.
- **Tools/Gateway**: 도구 연결 → 사용 시점 지시 → 결과 기반 다음 행동 → **불필요한 도구 호출 줄이기**(시간/비용 절감).
- **Guardrails**: 응답 제어 → 부적절 응답 방지 → 챌린지 규칙 준수 → 입출력 제어 이해.
- **Lambda**: Tool 호출 → 결과 확인 → 에이전트가 결과 활용.

## AI Assistant 활용 (워크샵 중) [확정]

코드 작성 / 오류 원인 분석 / 프롬프트 개선 / 에이전트 전략 수립 / 테스트 결과 분석 / 점수 개선 아이디어 도출.
→ 본 저장소 + 시뮬레이터를 AI Assistant 컨텍스트로 투입해 **반복 개선 속도**를 극대화.
