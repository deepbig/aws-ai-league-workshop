# 01. 워크샵 개요

## 무엇인가 [확정]

> "AWS AI League는 단순히 강의를 듣는 세션이 아니라, 제한된 시간 안에 지도를 탐색하여 보물을 얻는 에이전트를 만들고 개선하며 점수를 높여가는 **경쟁형 워크샵**입니다."

- 형식: **핸즈온 + 경쟁(리그)**. 점수로 순위가 매겨짐.
- 진행: 웹 브라우저 기반 실습 환경. 별도 로컬 개발환경 설치 불필요.
- 반복 개선형: 에이전트를 만들고 → 플레이 → 점수 확인 → 개선 → 재플레이 루프. **반복 사이클 수와 질이 점수를 좌우**.

## 빌드 스택 [확정]

- **Amazon Bedrock AgentCore** 중심으로 에이전트 구성.
- 에이전트 개발 요소: **Memory, Tool, Guardrails**.
- 코드 작성/수정: **AWS Lambda(Python)**, **Amazon SageMaker AI 내장 코드 에디터**.
- **AI Assistant 적극 활용 가능**: 코드 작성, 오류 분석, 데이터셋 생성, 프롬프트 개선, 에이전트 전략 수립, 테스트 결과 분석, 점수 개선 아이디어 도출.
  - 기본 제공: Amazon Q. 권장 사전설치: **Kiro**. 그 외 **Claude Code** 등 본인 선호 어시스턴트 사용 가능(회사 보안 정책 확인 필요).

## 게임 한눈에 [확정 + 추론]

게임 화면([assets/key-images/game-play.png](../assets/key-images/game-play.png))에서 직접 확인:

- 상단 지표 3종: **코인(점수) 2,250** / **생명(하트) 3** / **타이머 4:13 카운트다운**.
- **그리드 미로 맵** (열 A–J), 벽/통로, 코인 다수, 적(몬스터), 보물/아이템.
- **Combat Log** 패널: 에이전트가 풀어야 할 **챌린지(추론·수학 문제)** 표시. 예시로 "1000–1100 구간 연속 소수 간 최대 gap" 문제가 보임.

목표([assets/key-images/objective-and-tabs.png](../assets/key-images/objective-and-tabs.png)):

> **"보물을 찾으면서 모든 코인을 수집하고 챌린지를 물리치세요!"**

상세는 [docs/02-game-mechanics.md](02-game-mechanics.md) 참조.

## 당일 공개 항목 [당일]

안내자료의 게임 설정 화면에는 다음 영역이 **의도적으로 비어/가려져** 있습니다 → **워크샵 당일 최우선 확인**:

- **극대화하는 방법** (점수를 어떻게 극대화하는가 = 사실상 채점식)
- **추가 규칙**
- **챌린지** 탭 상세, **보너스** 탭 상세
- 정확한 점수 배점·동점 처리·페널티

안내자료 명시: *"챌린지, 보너스 점수 등 세부 규칙은 워크샵 당일 공개됩니다."*
*"가이드 및 힌트: 워크숍 스튜디오 문서에 연습 과정과 추가 팁이 포함되어 있습니다."* → 당일 이 문서를 가장 먼저 정독.

## 환경 접근 [확정]

- **AWS Builder ID 필수** (AWS 콘솔 계정과 다름). 워크샵 인프라용 AWS 계정은 주최 측 제공.
- 개인 노트북 + 충전기 필수. Chrome 최신 권장. 회사 VPN/보안정책으로 외부 접속·외부 AI Assistant가 막히는지 사전 확인.

상세 준비: [docs/05-prep-checklist.md](05-prep-checklist.md).
