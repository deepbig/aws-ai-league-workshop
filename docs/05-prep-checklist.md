# 05. 행사 전 필수 준비 체크리스트 [확정]

> 안내자료 경고: "현장에서는 별도 환경 설정 시간이 제공되지 않으며, 사전 준비 여부에 따라 실습 참여가 제한될 수 있습니다." → 아래는 **반드시** 사전 완료.

## A. 계정 / 접근 (필수)

- [ ] **AWS Builder ID 생성** (AWS Builder Center에서, 개인 이메일 가능)
- [ ] 생성 후 **재로그인 정상 동작 확인**
- [ ] 행사 당일 쓸 **이메일 계정·비밀번호 기억**, 인증메일/MFA 수신 가능 상태
- [ ] 회사 보안정책상 개인 이메일 사용 제한 여부 사전 확인
- [ ] (참고) AWS 콘솔 계정 ≠ Builder ID. 워크샵 인프라용 AWS 계정은 주최 제공 → 따로 준비 불필요

## B. 장비 / 네트워크 (필수)

- [ ] **개인 노트북 + 충전기** 지참
- [ ] **Chrome 최신 버전** 설치/업데이트
- [ ] 회사 VPN에서 외부 웹/개발환경 접속 가능 여부 확인
- [ ] 사내 보안정책으로 외부 개발환경 차단되지 않는지 확인
- [ ] 필요 시 **개인 핫스팟/대체 네트워크** 준비

## C. AI Assistant (권장 — 실습 효율 직결)

- [ ] **Kiro 설치** (공식 다운로드 → OS별 설치 → 실행)
  - [ ] 로그인(GitHub / Google / AWS Builder ID / IAM Identity Center 중)
  - [ ] 신규 사용자 50 크레딧/30일 확인, **Free tier 유지**(유료 불필요)
  - [ ] 사내망/VPN에서 Kiro 접속 가능 확인
  - [ ] 테스트 프롬프트로 정상 동작 확인
- [ ] (선택) **Claude Code** 등 선호 어시스턴트 — 회사 보안정책상 외부 AI Assistant 사용 가능 여부 사전 확인
- [ ] 기본 제공 Amazon Q 외 별도 어시스턴트를 준비(네트워크 상황 대비 이중화)
