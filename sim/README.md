# sim — 전략 사전 검증 시뮬레이터

관찰된 게임 메커니즘([docs/02](../docs/02-game-mechanics.md))을 파라미터화한 **무의존성(stdlib only)** 시뮬레이터.
실점수 예측기가 아니라 **어떤 전략 레버가 우월한지**를 가리고, 당일 채점식 변경에
즉시 대응하기 위한 도구.

## 실행

```bash
python3 sim/run.py         # 30 에피소드 ablation
python3 sim/run.py 100     # 에피소드 수 지정
```

## 당일 사용법

1. "극대화하는 방법 / 추가 규칙 / 챌린지·보너스 / 워크숍 스튜디오 문서" 정독
2. [`config.json`](config.json)의 값을 **실제 [확정]값**으로 교체
   (배점·페널티·보너스·시간·생명·코인 가치·암산 정확도 등)
3. `python3 sim/run.py` → 최고 점수 전략 분기 확인
4. 해당 정책/프롬프트를 실제 AgentCore 에이전트에 반영 ([docs/06](../docs/06-winning-strategy.md))

## 파일

- `config.json` — 모든 [당일]-미정 값. **여기만 바꾸면 전 전략 재검증.**
- `game.py` — 그리드 미로 환경 (맵·코인·적·챌린지·보물·예산)
- `agent.py` — 베이스라인 + 전략 토글(code_solve / budget_path / use_memory)
- `run.py` — 시나리오 ablation 리포트

## 참고 결과 (기본 config, 50 에피소드)

개별 레버는 소폭, **전부 결합 시 시너지로 급증**(예산경로로 챌린지까지 도달 →
코드풀이로 확실히 격파). → "한 레버만"이 아니라 "경로+챌린지 결합"이 1등의 핵심.
실제 수치는 `config.json`에 의존하며 당일 값으로 재산출 필요.
