4.1 Amazon Bedrock AgentCore
이번 워크샵의 중심이 되는 서비스입니다.
Amazon Bedrock AgentCore는 AI 에이전트를 만들고 실행하기 위한 기반 서비스입니다.
워크샵에서는 AgentCore를 활용해 에이전트가 어떤 모델을 사용할지, 어떤 도구를 호출할지, 어
떤 정보를 기억할지, 어떤 규칙 안에서 동작할지를 구성하게 됩니다.
쉽게 말해, AgentCore는 AI 에이전트가 실제로 움직이도록 만드는 실행 환경입니다.
워크샵에서 보게 될 내용:

 - 에이전트 생성 및 실행 - 에이전트의 역할과 행동 방식 정의 - 도구 연결 - Memory 설정
           적용
 - Guardrails




4.2 AgentCore Memory
AI 에이전트는 한 번 들은 정보를 나중에 다시 활용해야 할 때가 있습니다.
이때 사용하는 기능이 Memory입니다.
예를 들어 챌린지 중간에 어떤 힌트나 키 값을 얻었다면, 에이전트는 그 정보를 기억해두었다가 이
후 문제를 풀 때 다시 사용해야 합니다.
따라서 Memory는 단순 저장 기능이 아니라, 에이전트가 이전 맥락을 잊지 않고 다음 판단에 활
용하도록 돕는 기능입니다.
워크샵에서 다루게 될 내용:
 - 중요한 정보를 Memory에 저장하기 - 저장한 정보를 다시 불러오기 - System Prompt에
 서 Memory 사용 방식을 지시하기 - 기억한 정보를 바탕으로 후속 문제 해결하기



4.3 Tools / Gateway
AI 에이전트는 모든 일을 혼자 처리하지 않습니다.
필요한 경우 외부 도구를 호출해 경로 탐색, 계산, 코드 실행, 데이터 조회 같은 작업을 수행할 수
있습니다.
이때 에이전트와 외부 도구를 연결해주는 구조가 Tools 와 Gateway입니다.
쉽게 말해, Tools는 에이전트가 사용할 수 있는 작업 도구이고, Gateway는 그 도구들을 연결해
주는 통로입니다.
워크샵에서 다루게 될 내용:

 -에이전트가 사용할 도구 연결 - 언제 어떤 도구를 사용할지 지시 - 도구 실행 결과를 바탕
 으로 다음 행동 결정 - 불필요한 도구 호출 줄이기



4.4 Amazon Bedrock Guardrails
AI 에이전트는 주어진 규칙 안에서 안전하고 적절하게 동작해야 합니다.
Guardrails는 에이전트의 입력과 출력을 제어해, 원하지 않는 응답이나 부적절한 동작을 줄이는
안전장치입니다.
워크샵에서는 에이전트가 챌린지 규칙을 벗어나지 않고, 의도한 방식으로 응답하도록
Guardrails의 역할을 이해하게 됩니다.
워크샵에서 다루게 될 내용:

 - 에이전트 응답 제어 - 안전하지 않거나 부적절한 응답 방지 - 챌린지 규칙 준수 - 입력/출
 력 제어 방식 이해



4.5 AWS Lambda
워크샵에서 에이전트가 사용하는 일부 도구는 AWS Lambda로 구현됩니다.
Lambda는 서버를 직접 관리하지 않고도 특정 기능을 실행할 수 있는 서비스입니다.
예를 들어 에이전트가 경로를 찾거나, 계산을 수행하거나, 특정 데이터를 처리해야 할 때
Lambda 기반 도구를 호출할 수 있습니다.
워크샵에서 다루게 될 내용:
 - Lambda   기반 Tool 호출 - 도구 실행 결과 확인 - 에이전트가 결과를 활용하는 방식 이해

5. FAQ
  Q1. AWS 계정이 필요한가요?
  본 워크샵에서는 워크샵 인프라를 위한 AWS 계정을 별도 제공하므로, 따로 준비할 필요가
  없습니다.
  다만, 워크샵 실습 환경 접속을 위해 AWS Builder ID가 필요합니다.
  행사 전 AWS Builder ID를 생성하고 로그인 가능 여부를 확인해 주세요.


  Q2. AWS Builder ID와 AWS 계정은 같은 것인가요?
  AWS Builder ID는 AWS Builder Center, Workshop Studio 등 개발자용 학습 및 빌더
  경험에 접근하기 위한 로그인 ID입니다.
  일반적인 AWS Management Console 계정과는 용도가 다르므로, 행사 안내에 따라
  AWS Builder ID를 별도로 준비해 주세요.
Q3. 노트북 없이 참여할 수 있나요?
본 워크샵은 실습형 세션이므로 개인 노트북 지참이 필수입니다.
노트북과 충전기를 반드시 준비해 주세요.

Q4. 어떤 브라우저를 사용해야 하나요?
Chrome 브라우저 사용을 권장드립니다.
행사 전 최신 버전으로 업데이트해 주세요.

Q5. 사전에 개발 환경을 설치해야 하나요?
실습은 웹 브라우저 기반으로 진행됩니다.
복잡한 로컬 개발 환경 설치는 필요하지 않습니다.
다만 원활한 실습 진행을 위해 Kiro를 사전에 설치하고 로그인까지 완료해 오시는 것을 권장
드립니다.

Q6. Amazon Q가 제공되는데 Kiro도 설치해야 하나요?
워크샵 환경에는 Amazon Q가 제공되지만, 실습 환경이나 네트워크 상황에 따라 AI
Assistant 사용 경험이 달라질 수 있습니다. 원활한 실습 진행을 위해 Kiro 등 별도의 AI
Assistant 를 사전에 설치해 오시는 것을 권장드립니다.
Q7. Kiro 사용 시 비용이 발생하나요?
Kiro는 신규 사용자가 Free tier로 시작할 수 있습니다. 본 워크샵 참여를 위해 유료 플랜 가
입은 필요하지 않습니다.
단, Kiro의 유료 플랜으로 업그레이드하는 경우 별도 구독 비용이 발생할 수 있으므로, 워크
샵 목적이라면 Free tier 상태로 사용해 주세요.
